# 🌍 Traveloop – Assign Travel Dates, Activities, and Budgets

## 📌 Problem Statement

**Assign travel dates, activities, and budgets** using an interactive tourism planning system.

---

# 📖 Project Overview

Traveloop is a tourism and trip-planning web application that helps users organize their trips efficiently.  
Users can select travel dates, add day-wise activities, assign budgets, and track expenses in one place.

The system provides a clean, responsive, and user-friendly interface for smart travel management.

---

# ✨ Features

- 📅 Select trip start and end dates
- 🗺️ Destination planning
- 🧳 Day-wise trip planner
- 💰 Budget tracking system
- 📊 Expense progress bar
- ⚠️ Budget warning alerts
- 🍽️ Activity categorization
  - Food
  - Hotel
  - Sightseeing
  - Transport
  - Activities
- ✅ Save trip functionality
- 📱 Responsive UI design

# ⚙️ Working Flow

1. User enters trip details
2. User selects travel dates
3. System creates day-wise planner
4. User adds activities
5. User assigns activity costs
6. System calculates total expenses
7. Budget alerts are displayed
8. Trip data is saved

# 💰 Budget Tracking Logic

The system continuously:

- Calculates total activity expenses
- Compares expenses with total budget
- Displays warning alerts when budget exceeds limit
- Shows remaining budget amount
